## Descripción

Implementación en Java de la lógica de intercalación de bloques (`intercalarBloques`) para el algoritmo de ordenamiento externo **Mezcla Directa (Straight Merge)**. El programa lee dos archivos auxiliares (`f1.txt` y `f2.txt`) con bloques ordenados de tamaño $L$, compara sus elementos y genera un archivo de salida ordenado (`f3.txt`).

# Instalación y Ejecución

1 **Clonar el repositorio:**
git clone [https://github.com/Garrrido10/OrdenamientoExterno.git](https://github.com/Garrrido10/OrdenamientoExterno.git)

2 **Configurar e importar en IntelliJ IDEA:**

Abre IntelliJ IDEA y selecciona File > Open para cargar tu proyecto o copia MezclaDirectaPractica.java dentro de tu paquete correspondiente (por ejemplo, Estructura_De_Datos.Ordenamiento_Externo) y f1.txt / f2.txt en la carpeta raíz del proyecto.

Verifica que el SDK de Java esté configurado en File > Project Structure > Project > SDK.

3 **Verificar los archivos auxiliares:**

Confirma que f1.txt (con 45) y f2.txt (con 12) estén creados con un número por renglón antes de ejecutar.

4 **Ejecutar el programa:**

Abre MezclaDirectaPractica.java.

Haz clic en el botón Run (ícono de triángulo verde) junto al método main.
